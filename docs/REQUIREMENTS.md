## 7. من وثيقة المواصفات المرفقة (ملخص)

وثيقة «منصة اختبارات الزمالات» (56 صفحة) تضمنت أيضًا:

- أدوارًا إضافية ضمن النموذج المؤسسي (مراجِع، مصحّح، مراقب، مدقق) وتمت تغطيتها عبر صلاحيات المدير/الخبير/المدير الأعلى.
- دورة حياة السؤال: مسودة → قيد المراجعة → معتمد/مرفوض، مع إصدار جديد عند تعديل سؤال معتمد.
- أنواع أسئلة: اختيار واحد، اختيار متعدد، صح/خطأ، إجابة قصيرة، مقالي، رقمي.
- دخول الزميل **برقم الهوية الوطنية** المرتبط بتسجيله في الاختبار (بدون كلمة مرور).
- تعليمات وموافقات إلزامية + فحص جهاز قبل البدء.
- تسليم تلقائي عند انتهاء الوقت، واستئناف الجلسة عند انقطاع الاتصال.
- سجل تدقيق (Audit Log) لكل الإجراءات الحساسة.
- نشر النتائج بعد الاعتماد، واستعلام الزميل عن نتيجته.
- توثيق أي تعديل على الدرجات مع السبب واسم المعدِّل.
