# ما تم تنفيذه — التوثيق التقني الكامل

هذا الملف يشرح كل ما تم بناؤه: البنية، قاعدة البيانات، الـ API، مصفوفة الصلاحيات، محرك الذكاء الاصطناعي، القفل والمراقبة، ونسخة سطح المكتب، ونتائج الاختبار.

## 4. رحلة الزميل (تنفيذ §3–§6 من المتطلبات)

1. **الدخول** `/exam`: رمز الاختبار + رقم الهوية → تحقق من التسجيل والمحاولات والنافذة الزمنية.
2. **التحضير**: تعليمات ثنائية اللغة + موافقتان إلزاميتان (سياسة + مراقبة) + فحص جهاز (شاشة/متصفح/إنترنت/كاميرا).
3. **البدء**: جلسة بترتيب أسئلة وخيارات **مخلوط ببذرة مشتقة من رمز الجلسة** — كل زميل ترتيب مختلف، وثابت له عند الاستئناف. **الإجابات الصحيحة لا تغادر الخادم أبدًا.**
4. **أثناء الاختبار**: حفظ كل إجابة فوريًا (upsert)، نبضة كل 15 ثانية (مزامنة العداد + التمديد + الإيقاف)، عداد تنازلي، تنقل وعلامات مراجعة.
5. **التسليم**: يدوي بتأكيد يعرض غير المجاب، أو **تلقائي عند انتهاء الوقت** (من جهة الخادم أيضًا).
6. **التصحيح الفوري**: الموضوعية آليًا (الاختيار المتعدد برصيد جزئي)، المفتوحة → اقتراح ذكي + كاشف ذكاء اصطناعي.
7. **النتيجة**: بعد الاعتماد والنشر، يستعلم الزميل من نفس البوابة.

## 5. محرك الذكاء الاصطناعي (`api/lib/aiEngine.ts`)

| الوظيفة | الآلية |
|---|---|
| **توليد أسئلة** | توليد أسئلة من موضوع/كفاءة بأنواع وصعوبة محددة، عربي + إنجليزي، تُحفظ **مسودات** تحتاج اعتمادًا قبل الاختبار |
| **توليد مشابهة** | اشتقاق نسخ من أي سؤال في البنك (صياغة بديلة + إعادة ترتيب خيارات مع إبقاء الإجابة الصحيحة متطابقة) |
| **اقتراح تصحيح** | تحليل تغطية مفاهيم الإجابة النموذجية + الطول + التنوع المعجمي + البنية → درجة مقترحة + ملاحظات عربية **يعتمدها الخبير أو يعدّلها** |
| **كاشف النص المولّد** | 6 مؤشرات لغوية: انتظام أطوال الجمل، الروابط الرسمية النمطية، القوائم المثالية، التنوع المعجمي، غياب العامية، الخواتم النمطية → نسبة 0–100% وتصنيف |

## 6. القفل والمراقبة الذكية

### في المتصفح (وضع القفل الآمن)
- ملء شاشة إجباري — الخروج يُسجَّل ويظهر غطاء إجباري للعودة.
- رصد: إخفاء التبويب، فقدان التركيز، النسخ/اللصق/القص، الزر الأيمن، اختصارات محظورة (F12، Ctrl+P/S/U…)، محاولة مغادرة الصفحة.
- كل حدث يُسجَّل بخطورة (info→critical) ويرفع **درجة الخطورة** للجلسة.

### لوحة المراقبة المباشرة (تحديث كل 5 ثوانٍ)
- إحصاءات: مسجلون/بدأوا/نشطون/سلّموا/موقوفون + متوسط الخطورة.
- لكل جلسة: العداد الحي، الأحداث، IP، درجة الخطورة.
- إجراءات: مراجعة حدث (سليم/مشتبه/مخالفة)، **تمديد الوقت**، **إيقاف الجلسة**.

## 7. نسخة سطح المكتب (`desktop/`)

تطبيق **Electron** يلبي المتطلب حرفيًا:

- **يقفل كافة الأمور**: وضع Kiosk بملء الشاشة دائمًا، بلا إطار، حظر Alt+Tab / Alt+F4 / F11 / F12 / PrintScreen واختصارات النظام أثناء الاختبار (نافذة + نظام).
- **مرتبط بالموقع فقط**: منع التنقل خارج نطاق المنصة + حظر شبكي لأي وجهة أخرى + منع نوافذ جديدة.
- **لا يُغلق أثناء الاختبار**: الإغلاق يتطلب رمز المراقب (PIN في `config.json`).
- **الأسئلة والتسليم عبر الموقع**: يفتح `/exam` مباشرة، والحفظ لحظي على الخادم — انقطاع الكهرباء لا يفقد إجابة، والجلسة تُستأنف تلقائيًا.
- التكامل: صفحة الاختبار ترسل `exam-started`/`exam-finished` للتطبيق عبر `preload.js`.

```bash
cd desktop && npm install
npm start          # تشغيل
npm run dist:win   # مثبّت Windows
npm run dist:mac   # حزمة macOS
```

**`test/e2e-test.mjs`: 50/50 ناجح** على نسخة الإنتاج، يغطي:

| المجموعة | الحالات |
|---|---|
| المدير الأعلى | دخول، المستخدمون، سجل التدقيق |
| المدير | إحصائيات، إضافة/استيراد زملاء، إنشاء خبير، تسجيل بالهوية، تعيين مشرف |

بالإضافة إلى تجربة واجهة فعلية عبر متصفح آلي: الرئيسية (عربي/إنجليزي)، دخول المدير، إدارة الاختبار، ورحلة زميل كاملة (دخول → موافقات → بدء → إجابة → حفظ تلقائي → تنقل).

## 9. قرارات تقنية ملحوظة

- **لا تسريب للإجابات**: نقطة `candidate.state` تعيد الأسئلة بدون `correctAnswer` نهائيًا.
- **الخلط الحتمي**: بذرة من رمز الجلسة — عشوائي بين الزملاء، ثابت للزميل نفسه عند الاستئناف.
- **العداد بمرجعية الخادم**: الموعد النهائي مخزن، والتمديد `timeAdjustmentSec` ينعكس فورًا في النبضة التالية.
- **الهوية المقنّعة**: رقم الهوية الكامل لا يظهر في قوائم المراقبة/التصحيح، بل `10******01`.
- **تعديل سؤال معتمد** ينشئ إصدارًا جديدًا ويعيده مسودة (نزاهة بنك الأسئلة).
- **ملف `.env` غير مرفوع** على المستودع — استخدم `.env.example`. (الشعار `public/logo.png` يُضاف من نسخة التسليم لأنه ملف ثنائي).
