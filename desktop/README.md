# نسخة سطح المكتب الآمنة — الاختبار المقفل

تطبيق Electron يقفل جهاز الزميل بالكامل أثناء الاختبار ويتصل بمنصة الزمالات المهنية فقط.

## المزايا

- **قفل كامل للجهاز**: وضع Kiosk بملء الشاشة دائمًا — حظر Alt+Tab وAlt+F4 وF11 وF12 وPrintScreen واختصارات النظام أثناء الاختبار.
- **مرتبط بالموقع فقط**: يمنع التنقل أو تحميل أي محتوى من خارج نطاق المنصة (على مستوى النافذة والشبكة).
- **لا يُغلق أثناء الاختبار**: الإغلاق يتطلب رمز المراقب (PIN) بعد إنهاء الجلسة.
- **نسخة واحدة فقط**: منع تشغيل أكثر من نسخة.
- **حفظ أول بأول**: الإجابات تُحفظ لحظيًا على المنصة، فلا تضيع أي إجابة حتى عند انقطاع الكهرباء — ويستأنف الزميل جلسته تلقائيًا.

## التشغيل للتطوير

```bash
cd desktop
npm install
# عدّل config.json وضع رابط المنصة
npm start
```

## بناء نسخة التنزيل للأجهزة

```bash
# Windows (ملف تثبيت .exe)
npm run dist:win

# macOS (ملف .dmg)
npm run dist:mac
```

## الإعدادات (config.json)

| الحقل | الوصف |
|------|-------|
| `platformUrl` | رابط المنصة الذي يقفل عليه التطبيق |
| `proctorExitPin` | رمز خروج المراقب — يُغيَّر لكل قاعة |

## آلية العمل مع المنصة

1. يفتح التطبيق بوابة الاختبار `/exam` مباشرة في وضع القفل.
2. عند بدء الزميل للاختبار ترسل الصفحة `lockdown:exam-started` فيتشدد القفل.
3. نظام المراقبة الذكي في المنصة يسجل كل الأحداث (محاولات الخروج، فقدان التركيز...) ويظهرها في لوحة المراقبة المباشرة.
4. عند التسليم تُرسل `lockdown:exam-finished` ويُخفَّف القفل.
